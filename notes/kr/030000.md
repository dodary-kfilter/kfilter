# 제일기획 (030000) — 콘텐츠(광고: 광고 기획·제작, 매체 구매 대행, 리테일·체험 마케팅 — 삼성 계열이 주 광고주)
업데이트: 2026-11-23 (처음 분석 — 3분기 잠정 실적(10/30)의 원인과 증권사 전망, 분기보고서(2026.09) 누적 숫자를 확인 · 11/23 -3.28% · 판단 변경 없음)
## 무엇으로 돈 버나
- 1973년 광고업으로 세웠고 1998년 상장했다(번들 사업 개요).
- 46개국 55개 거점의 해외 조직을 운영한다 — 영국 아이리스(Iris), 미국 TBG·맥키니(McKinney), 중국 펑타이(PengTai)를 거느린다(번들 사업 개요).
- 광고 기획·제작, 매체 선정·구매 대행, 프로모션을 판다(번들 사업 개요).
- 매출은 매체 집행과 광고물 제작으로 나뉜다(분기보고서 2026.09 발췌 — 번들).
- 매체는 매체비를 뺀 대행 수수료만 매출로 잡고, 제작은 총액을 매출로 잡는다(같은 출처).
- 그래서 매출보다 매출총이익(회사 표현으로 영업총이익)이 실제 장사를 더 잘 보여 준다(판단).
- 3분기 매출총이익에서 삼성 계열 물량이 약 70%다(웹 검색 요약 11/23 — 증권사 보고서).
- 3분기 리테일·체험 마케팅 매출총이익은 1년 전보다 12.5% 줄었다(웹 검색 요약 11/23).
- 1~3분기 누적 연결 매출은 1년 전보다 6.5%, 매출총이익은 1.1% 줄었다(분기보고서 2026.09 발췌 — 번들).
- 3분기 매출총이익과 계열·비계열, 국내·해외 숫자는 확인 불가다 — 분기보고서 표를 번들이 줄였다(번들).
## 경쟁력
- 국내 1위 광고회사이고, 삼성이라는 큰 광고주를 안정적으로 갖고 있다(알려진 사실 · 판단).
- 비계열 광고주를 늘려 왔다 — 10/30 판단은 '3분기 북미·중남미 성장과 비계열 광고주 확대'를 이유로 적었다(picks.json 이유 셋째 줄).
- 비계열 매출총이익이 1년 전보다 5% 늘었다는 증권사 분석이 있다 — 어느 기간인지는 확인하지 못했다(웹 검색 요약 11/23 — 키움 보고서).
- 이익률이 업종 평균과 같다 — 2분기 영업이익률 8.63%, 업종 8.53%다(kr_fund · 2분기 기준).
- 3분기 영업이익률은 7.41%로 1년 전 8.07%보다 0.66%p 내렸다(10/30 잠정 공시 · 번들 · 계산).
- 주주환원이 크다 — 자사주 1,376만 주(소각 전 발행주식의 12.0%)를 소각했다(10/27 변경상장 · 10/30 판단 기록 · 계산).
- 400억원어치 자사주를 더 사서 소각한다 — 시총 1조8,534억원의 2.2%, 18,300원으로 약 219만 주다(10/30 판단 기록 · 번들 · 계산).
- 400억원 매입이 얼마나 진행됐는지는 확인 불가다.
- 주당 배당금 1,230원은 18,300원의 6.72%다(kr_fund dps · 계산).
- 배당 총액은 약 1,246억원으로, 최근 네 분기 순이익 2,018억원의 62%다(계산).
- 자사주 400억원을 더하면 최근 네 분기 순이익의 82%를 돌려준다(계산).
- 3분기 순이익 456억원이 네 분기 이어져도(연 1,824억원) 배당 총액은 순이익의 68%다 — 지금 배당은 이익으로 감당된다(계산 · 판단).
- 외국인 지분율은 21%다(kr_fund).
## 숫자 (기준일 · 출처)
- 분기 실적(억원, 매출·영업이익·순이익)은 2025년 3분기 11,889·959·649, 4분기 11,997·904·644다(번들).
- 2026년 1분기 10,176·365·283, 2분기 10,745·927·635, 3분기 10,390·770·456이다(번들 · 10/30 잠정 공시 · 10/31 판단 기록).
- 3분기는 1년 전보다 매출 12.6%, 영업이익 19.7%, 순이익 29.7% 줄었다(계산).
- 3분기 지배주주 순이익은 1년 전보다 30.66% 줄었다(웹 검색 요약 11/23 — 실적 공시).
- 3분기 영업이익은 2분기보다 16.9% 적다(10/30 잠정 공시).
- 부진의 원인은 삼성전자 MX(휴대폰) 사업부의 마케팅 축소다(웹 검색 요약 11/23 — 증권사 보고서·보도).
- 메모리 단가가 올라 MX 사업부의 이익이 줄었고, 그래서 마케팅비를 보수적으로 썼다(같은 출처).
- 삼성증권은 9/16 목표가를 23,500원에서 21,000원으로 낮췄다 — 3분기 영업이익을 818억원(-14.7%)으로 봤다(웹 검색 요약 11/23).
- 그때 시장 컨센서스는 1,008억원이었다(같은 출처).
- 실제 770억원은 삼성증권 추정보다 5.9%, 9월 컨센서스보다 23.6% 적다(계산).
- 10/6에도 3분기 영업이익 819억원(-15%)으로 컨센서스를 크게 밑돈다는 보고서가 나왔다(웹 검색 요약 11/23 — 증권사 이름은 확인 못 함).
- 앞서 현대차증권은 7월에 목표가를 25,000원에서 27,000원으로 올렸고, 한화투자증권은 3월에 25,000원으로 낮췄다(웹 검색 요약 11/23).
- 3분기 실적 뒤(10/30 이후) 증권사 목표가는 확인 불가다.
- 최근 네 분기 순이익 2,018억원을 1억128만주로 나눈 EPS는 1,993원, PER은 9.2배다(번들 · 계산).
- 다음(Daum) PER은 9.23배, 업종 PER은 9.82배다(kr_fund).
- 번들의 최근 두 분기 연환산 PER은 11.5배다 — 3분기가 빠진 2026년 1·2분기 기준이다(번들).
- PBR은 1.22배, 연환산 ROE는 11.74%다(kr_fund).
- EV/EBIT는 4.4배로 업종 10.8배의 0.4배다(kr_fund).
- 같은 광고회사 이노션은 PER 7.35배, PBR 0.63배, 배당 수익률 7.14%, ROE 10.5%다(kr_fund · 계산).
- 제일기획 PBR은 이노션의 1.9배다 — 이노션보다 비싸게 거래된다(계산).
- 11/23 가격은 18,300원(-3.28%), 시총은 1조8,534억원이다(번들 장 마감).
- 20일 수급은 외국인 33,159주 순매수, 기관 593,290주 순매도다(번들 11/23).
- 기관 순매도는 발행주식의 0.59%다(계산).
- 10/30 판단 때 외국인 20일 순매수는 44만 주였다 — 외국인의 매수가 거의 멈췄다(10/30 판단 기록 · 번들 · 판단).
- 원·달러는 1,347.2원으로 10/31(1,335.8원)보다 0.85% 올랐다 — 해외 이익을 원화로 바꿀 때 조금 유리해졌다(번들 · 10/31 판단 기록 · 계산).
- 업종 점수는 콘텐츠 52.6으로 국장 20개 업종 중 6위다 — 아침 판단 때 58이었다(후보 표 업종 점수 11/23 12:16 · picks.json).

- 한 광고주에 기댄다 — 삼성 계열 물량이 매출총이익의 약 70%다(웹 검색 요약 11/23).

- 이익이 줄면 배당을 줄일 수 있다 — 배당 정책(배당 성향 목표 등)은 확인 불가다(판단).
