# 인슐릿 (PODD) — 헬스케어(인슐린 펌프)
업데이트: 2026-11-14 (처음 분석 — 11/14 04:52 판단에서 적극형에 편입한 종목, 노트 없이 넣었다)
## 무엇으로 돈 버나
- 튜브 없이 몸에 붙이는 인슐린 펌프 옴니팟(Omnipod)을 판다(2025년까지의 회사 자료 · 판단).
- 주력은 연속혈당측정기(CGM)와 이어져 인슐린 양을 스스로 맞추는 자동 인슐린 주입(AID) 시스템 옴니팟 5다(2025년까지의 회사 자료 · 벤징가 제목).
- 며칠 쓰고 버리는 팟(pod)을 계속 사야 해서, 환자가 늘수록 반복 매출이 쌓인다(판단).
- 제품별 매출 비중은 확인 불가다(번들 재무 못 받음 — 나스닥 API 403).
- 3분기 매출 8.42억 달러(+19.2%, 고정환율 +19.6%) 중 미국은 약 15%, 미국 밖은 약 33% 늘었다(SEC 8-K · 웹 검색 11/14).
- 1형 당뇨에서 2형 당뇨로 넓히는 중이다 — 2형용 완전 자동(폐쇄 루프) 시스템의 FDA 510(k) 신청을 2027년에 노린다(웹 검색 11/14 · 실적 콜).
## 경쟁력
- 튜브가 없다는 것이 차별점이었는데, 새 튜브 없는 경쟁 제품에 점유율을 잃었다고 회사가 인정했다(finviz · 웹 검색 11/14).
- 경쟁 제품의 이름과 점유율 숫자는 확인 불가다.
- 미국 신규 환자 수는 늘지 않고 제자리였다고 회사가 3분기 실적 콜에서 밝혔다(finviz · Earnings Whispers · 웹 검색 11/14).
- 미국 밖 성장 전망은 32~33%로, 올해 네 번째로 올렸다(웹 검색 11/14).
- 3분기 영업이익률(GAAP)은 22.5%로 8분기 중 가장 높다 — 1년 전은 16.7%, 2분기는 16.2%였다(us_fund · 계산 · finviz '사상 최고 이익률').
- 2027년에 옴니팟 6을 낸다 — 스스로 배우는 알고리즘, 더 많은 CGM 연결, 새 앱·컨트롤러를 넣는다(웹 검색 11/14 · 실적 콜).
## 숫자 (기준일 · 출처)
- 분기 매출(억 달러)은 2025년 3분기 7.06, 4분기 7.84, 2026년 1분기 7.62, 2분기 8.02, 3분기 8.42다(us_fund).
- 1년 전 대비 매출 성장은 2025년 4분기 +31.2%, 2026년 1분기 +33.9%, 2분기 +23.5%, 3분기 +19.2%로 내려왔다(us_fund · 계산).
- 분기 영업이익(억 달러)은 2025년 3분기 1.18, 4분기 1.46, 2026년 1분기 1.22, 2분기 1.30, 3분기 1.90이다(us_fund).
- 3분기 순이익은 1.41억 달러로 1년 전보다 61.1% 많다(us_fund).
- 3분기 조정 EPS는 1.99달러(+59.9%)로 예상 1.59달러보다 25.2% 많았다(Earnings Whispers · 웹 검색 11/14 · 계산).
- 올해 매출 전망은 32.8~33.0억 달러, 고정환율 성장 21~22%(기존 20~22%)다 — 조정 EPS는 30% 넘게 는다고 했다(웹 검색 11/14).

- 4분기 매출 전망을 8.90~9.17억 달러로 적은 자료도 있다 — 연간 전망과 맞지 않아 확인 불가로 둔다(웹 검색 11/14).
- 2027년 전체 성장은 '15% 안팎보다 조금 아래', 미국 성장은 장기 틀 9~14%의 아래쪽으로 낮춰 잡았다(웹 검색 11/14 · 실적 콜).
- 최근 4분기 합계는 매출 31.89억·영업이익 5.88억·순이익 4.29억 달러다(us_fund).
- 시총은 104억 달러, PER 24.2배, EV/EBIT 19.0배다(us_fund 11/13).
- 미장 헬스케어 후보 13개의 PER 중앙값은 29.8배, EV/EBIT 중앙값은 19.3배, 최근 분기 매출 성장 중앙값은 8.8%다(후보 표 · 계산).
- 인슐릿의 PER은 그 중앙값의 0.81배인데, 매출 성장은 2.2배다(계산).
- 3분기 조정 EPS 연환산 7.96달러 기준으로 152.48달러는 19.2배다 — 목표가 180달러는 22.6배, 손절가 138달러는 17.3배다(계산).

- 10억 달러 자사주 매입(시총의 9.6%)을 승인했고, 4분기에 약 4억 달러(3.8%)를 가진 현금으로 쓴다(웹 검색 11/14 · 계산).
- 4억 달러를 쓰면 순부채는 영업이익의 약 2.1배로 는다(계산 · 판단, 3분기 말 현금 기준).
- 애널 의견·목표가·공매도·내부자 자료는 확인 불가다(번들 — 나스닥 API 403).

## 무너뜨릴 위험
- 튜브 없는 경쟁 제품이 미국 신규 환자를 가져간다 — 미국 신규 환자는 이미 제자리다(finviz · 웹 검색 11/14).
- 성장이 매 분기 내려온다 — 4분기 계산 성장은 11.6~14.1%, 2027년은 '15% 안팎보다 조금 아래'다(us_fund · 웹 검색 11/14 · 계산).
