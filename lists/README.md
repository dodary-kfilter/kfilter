# 투자 참고 리스트 (lists/)

최종 갱신: 2026-10-11

이 문서는 두 가지 리스트를 관리한다. 하나는 월가 상위 애널리스트의 추천 종목이고, 다른 하나는 13F 공시로 본 거물 투자자들의 공통 매매다. 둘 다 매수 신호가 아니라 후보를 고르는 출발점으로 쓴다.

## 파일 구성

- `README.md`: 운영 규칙과 현재 리스트(사람이 읽는 판)
- `analyst.json`: 월가 상위 애널리스트 추천 — TipRanks 상위 100위 애널리스트의 최근 28일 매수 의견(애널리스트별 `analysts`, 종목별 묶음 `stocks`)
- `tools/analyst_fetch.py`: `analyst.json`을 만드는 수집기(TipRanks에서 직접 받는다)
- `names_ko.json`: 미장 티커 → 한글 종목명. 수집기가 붙이고, 없으면 영문명으로 나간다
- `13f/2026Q2.json`: 13F 2분기 집계(상위 리스트, 합의 강도, 제외 종목, 전체 종목 인원)
- `13f/index.json`: 사이트가 읽을 최신 분기(`latest`). 새 분기 파일을 올리면 여기 `latest`도 바꾼다
- `history/analyst/날짜.json`: 애널리스트 리스트 주간 기록(수집기에 `--history`를 붙이면 남는다. 2026-10-06은 이전 CNBC 방식)

사이트(index.html)의 **애널 추천·13F 탭**이 `analyst.json`과 `13f/index.json`이 가리키는 분기 파일을 읽어 보여 준다(읽기만 함). 이 폴더의 자료는 수급 스캔(scanner.py, update.yml)과 무관하고, 사이트·스캔 파일을 읽거나 바꾸지 않는다.

## 운영 규칙

### 월가 상위 애널리스트 추천
- 출처: TipRanks(약 12,500명의 애널리스트를 적중률·평균 수익률로 매기는 순위). 순위표와 애널리스트별 최신 의견을 직접 받는다. 웹 페이지는 Cloudflare로 막혀 있어 curl로 API만 부른다.
- 범위: 최근 28일(갱신일 포함) 안에 낸 매수(Buy) 의견, 미국 상장·거래 중 종목만.
- 랭킹순(잘하는 소수): 상위 25위 애널리스트를 순위대로, 각자의 매수 의견 종목.
- 추천 수순(많이 추천): 상위 100위 가운데 2명 이상이 매수 의견을 낸 종목, 인원순(같으면 최고 순위순).
- 항목: 종목, 의견일, 의견 종류(유지·재확인·상향·신규 분석·의견 제시), 목표가, 상위 100위 중 매수 인원.
- 다루지 않는 것: 추천 이후 수익률.
- 순위가 최근 수익률 중심이라 상위권이 반도체·IT 담당에 몰려 있고, 리스트도 그쪽으로 기운다.
- 이전(~10월 6일)에는 CNBC 주말 연재(3종목씩)를 모았다. 연재가 순위 4~945위를 섞어 골라 '상위만'이 아니었고 겹침도 거의 없어 바꿨다.

### 13F 공통 매매
- 출처: Dataroma가 모아 보여 주는 슈퍼투자자 83명의 13F(미국 SEC에 내는 분기 보유 내역 공시).
- 시점: 분기 말 보유 내역을 45일 안에 공시한다. 갱신은 2·5·8·11월 중순이다.
- 리스트: 신규 편입, 비중 확대, 비중 축소, 청산(전량 매도) 4개. 같은 행동을 한 인원순이며, 2명 이상만 넣는다.
- 제외: ETF와 분기 중 새로 상장된 종목(분사·신규 상장으로 자동 편입된 물량)은 뺀다.
- 매수:매도: 그 종목을 사거나 늘린 인원 대 줄이거나 판 인원. 한쪽으로 쏠린 종목이 진짜 합의이고, 비슷하면 의견이 갈린 것이다.
- 한계: 공시가 늦고(최대 45일), 매수 포지션만 나오며, 분기 중 매매와 매수 가격은 보이지 않는다.
