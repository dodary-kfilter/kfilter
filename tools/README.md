

## 프롬프트 버전 확인 (2026-10-22, 프롬프트 v58~)
- 사이트 프롬프트의 자료 명령 끝에 `--ver vNN`이 붙는다. 번들은 저장소 `index.html`의 `PROMPT_VER`와 비교해,
  꼬리표가 없거나 최신보다 낮으면 자료를 내주지 않고 '#옛 프롬프트' 한 줄만 낸다(사용자에게 새로고침 후 다시 복사 요청).
- 배포 직후 몇 분은 저장소 파일이 옛 버전으로 보일 수 있어 '최신보다 낮을 때만' 막는다.
- 직접 실행(포트폴리오 대장·개발 확인 등)은 `--ver dev`를 붙인다. 예: `curl -s …/tools/bundle.py | python3 - us SPY --ver dev`
